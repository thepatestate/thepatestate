# THE PATE STATE ARTICLE PLAYBOOK — v3.0
### The editorial operating system: 13 buckets, 100+ typed articles, five pillars, one accountability spine.
**Supersedes v2.0.** Pair with: josh-pate-voice-manual-v2.md (how everything sounds) · pate-state-editorial-strategy.md (the lane and the allocation) · article-selection-engine.md (how the pipeline picks types) · wire-desk-breaking-news-manual.md (the speed lane) · operations-manual-v1.2.md (approvals, bylines, publishing authority).

**Who this is for:** Claude Code, the article agents, the selection engine, and any human editor. This document is the single source of truth for WHAT gets written. The Voice Manual is the single source of truth for HOW it sounds. If those two documents conflict with anything else, they win.

## 0. THE LAWS
- **FACT → MECHANISM → EDGE.** Every article answers three layers: *what happened → why it matters on a football field → what commodity coverage isn't telling the reader.* No EDGE, no publish. (Formerly the Three-Layers Rule; the shorthand is now official.)
- **The Two-Desk System.** The Wire answers "what happened," fast and autonomous. Everything else answers "so what," "who's actually good," "what happens next," or "what does Josh think." Josh-voice articles require human approval per Operations Manual §13 — the byline is never auto-applied.
- **Everything feeds the flywheel.** Every article ends in a franchise action: Pick'Em, Pulse, Poll, Ledger, YouTube, citizen registration. No cul-de-sacs.
- **Every type has an ID.** The selection engine, the CMS, and the assignment sheet all speak the same code (GD-01, NR-01, RK-04...). New types get IDs before anyone writes them.
- **Every type has a Tier.** T1–T4 (defined in §2). Ninety-plus types are not ninety-plus priorities. The tier tells the newsroom — human or agent — what actually matters.

**Brand guardrails applied throughout (from Voice Manual v2.0):**

- **Descriptive titles only.** This is law. The canonical example is Josh's own Ohio State correction. Evocative titles were tried and rejected.
- **No "overrated" dunk-framing.** The house construction is "the market is too high on."
- **No betting-tout language.** Ever.
- **Flaws belong to units and situations, never named kids.** "Alabama has a protection problem," not "this guard is terrible." Applies to SELLs, fatal-flaw pieces, grades, everything.
- **Every prediction writes to the Ledger** with a timestamp and a named grading date. No ungraded predictions exist. Corrections are timestamped, never silent.
- **The Film Room** is the anonymous house analytical voice — never attached to any real analyst's name. Its methods: credit-the-opponent-first, mechanism-over-adjective, ecosystem effects, continuity accounting, dose-response reasoning, the margins ledger.
- **The Consistency Ledger:** the same game never has two winners across any two articles on the site. Every commissioned piece is checked against it. Standing facts to carry: Georgia is JP Poll No. 1; **Josh's national champion pick is Notre Dame**; the two-questions framing (the poll answers twelve Saturdays, the championship answers January).
- **Selective reaction, never aggregation.** We don't write because somebody said something. We write because what they said creates an argument Josh can own.

## 2. DEPTH CLASSES & PRIORITY TIERS
### Depth classes (editorial depth first, word counts second)
Word counts are typical ranges, not quotas. The operative instruction for every agent: **write until the article's job is finished, then stop.** Padding to hit a range is a defect.

- 🔵 **BRIEF** — answer one question quickly. *Typically 250–500.*
- ⚪ **STANDARD** — one clear argument with evidence. *Typically 500–900.*
- 🟢 **FEATURE** — multiple layers/mechanisms with original analysis. *Typically 800–1,500.*
- 🟣 **DEFINITIVE** — the canonical treatment; nothing meaningful omitted. *Typically 1,500–2,500+.*
### Priority tiers
- **T1 — FRANCHISE.** Must publish on cadence. These are the rituals. Missing one is an incident.
- **T2 — CORE.** High-priority recurring. Publishes most weeks in its season.
- **T3 — TRIGGERED.** Publishes when the selection engine's trigger fires (news event, calendar date, ranking movement).
- **T4 — OPPORTUNISTIC.** Use selectively when the argument is genuinely there.

**The T1 roster (the rituals):** CC-01 Porch Report (daily) · RK-01 JP Poll (weekly in-season) · GD-01 Game Breakdown (weekly, Game of the Week) · GD-14 Watch List (Saturday AM) · GD-21 Saturday Blueprint (Friday PM/Saturday AM) · GD-16 What We Learned (Sunday) · GD-22 Sunday Truths (Sunday) · PR-01 Weekly Picks (Friday) · MD-03 Josh vs. the Model (Friday) · PO-01 Playoff Picture (weekly from October) · NR-01 What It Means (event-triggered but franchise-grade) · PR-06 Receipts (midseason + January).

## 3. GAME WEEK TIERS (the volume governor)
The taxonomy is deep; the weekly output is disciplined. Three games do NOT get 8–12 pieces each. The hierarchy itself tells the fan what Pate State thinks matters.
### TIER A — THE PATE STATE GAME OF THE WEEK (one game per week)
The full treatment, 7–10 pieces on the fixed rhythm, all attached to the game hub (§4):

Mon **GD-13** stakes → Tue **GD-05 or GD-06** (pick the matchup layer that's actually the story) + **GD-07** → Wed **GD-08** Game Grade → Thu **GD-01** flagship breakdown → Fri **GD-03** keys (both editions) + **GD-11/GD-12** predictions → Sat AM slot inside **GD-14** → Sat night **GD-15** → Sun folded into **GD-16**.

"Game of the Week" is a brand. The selection engine nominates; Josh (or the editor) confirms by Sunday night.
### TIER B — MARQUEE GAMES (2–4 per week)
Each gets: **GD-02** preview · **GD-03** keys (single combined edition) · combined prediction treatment (**GD-11 + GD-12** in one piece) · postgame inclusion in **GD-15/GD-16**. Roughly 3–4 pieces.
### TIER C — REST OF THE NATIONAL SLATE
Covered entirely through the slate franchises: **GD-20** Weekly Slate Guide · **GD-14** Watch List · **PR-01** Picks · **GD-17** Upset Alert. No standalone previews.

**Anti-cannibalization rule for agents:** within one matchup, no two articles may answer the same question. Before commissioning a Tier A derivative, the engine checks the hub's existing modules. Duplication is a commissioning failure, not a writing failure.

## 4. THE GAME HUB (GD-01 is a URL, not just an article)
For every Tier A game (and CFP games), the canonical matchup URL is created Monday and accumulates all week:

/college-football/georgia-vs-alabama-2026/

- **Mon:** hub opens with GD-13 (Why This Game Matters) as the lead module
- **Tue–Wed:** matchup layers and the Game Grade attach as modules/links
- **Thu:** GD-01 Complete Breakdown becomes the hub centerpiece
- **Fri:** model + Josh predictions attach; Ledger entries link live
- **Sat:** watch-list items + verified injury/availability updates
- **Sun:** final score, GD-16 grading of our own preview claims, Ledger resolution

One SEO object accumulating authority all week instead of six pages competing. Supporting articles still exist as standalones and cross-link into the hub. This is a build requirement for Isaac as much as an editorial rule — the hub template ships with module slots matching the rhythm above, and the homepage dedup rule (already specced) treats hub modules as already-shown content IDs.
