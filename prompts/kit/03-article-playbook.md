# THE PATE STATE ARTICLE PLAYBOOK — v3.1
### The editorial operating system: 13 buckets, 100+ typed articles, five pillars, one accountability spine.

**Part of the v1.0 kit.** Load order and companions: `01-constitution.md` (the laws) · `02-voice-bible.md` (how everything sounds) · `04-spec-wire.md` / `05-spec-annual.md` / `06-spec-features.md` (how each product is built) · `07-current-state.md` (what's true right now). This file answers one question: **WHAT gets written, when, and how deep.** Voice rules live only in the Voice Bible; this file never restates them.

---

## 0. THE OPERATING RULES

1. **FACT → MECHANISM → EDGE.** Every article: what happened → why it matters on a football field → what commodity coverage isn't giving the reader. No EDGE, no publish.
2. **The Two-Desk System.** The Wire answers "what happened," fast and autonomous. Everything else answers "so what," "who's actually good," "what happens next," or "what does Josh think." Lane rules: Constitution §3.
3. **Everything feeds the flywheel.** Every article ends in a franchise action. No cul-de-sacs.
4. **Every type has an ID.** The selection engine, the CMS, and the assignment sheet all speak the same code. New types get IDs before anyone writes them.
5. **Every type has a Tier.** T1–T4. A hundred types are not a hundred priorities.
6. **Selective reaction, never aggregation.** We don't write because somebody said something. We write because what they said creates an argument the house can own.
7. **Quality over volume.** The weekly output is governed by the Game Week Tiers (§3) and the T1 cadence — never by a quota. Skipping a T3 piece is free; publishing a mediocre one is expensive.

## 2. DEPTH CLASSES & PRIORITY TIERS

Depth classes are editorial-depth-first; word counts are typical ranges, never quotas. **Write until the article's job is finished, then stop.** Padding is a defect. (Annuals are the exception with no ceiling at all — spec §05.)

- 🔵 **BRIEF** — answer one question quickly. *Typically 250–500.*
- ⚪ **STANDARD** — one clear argument with evidence. *Typically 500–900.*
- 🟢 **FEATURE** — multiple layers/mechanisms with original analysis. *Typically 800–1,500.*
- 🟣 **DEFINITIVE** — the canonical treatment; nothing meaningful omitted. *Typically 1,500–2,500+, no ceiling.*

Tiers: **T1 FRANCHISE** (must publish on cadence — missing one is an incident) · **T2 CORE** (most weeks in season) · **T3 TRIGGERED** (fires on event/date/movement) · **T4 OPPORTUNISTIC** (only when the argument is genuinely there).

**The T1 roster:** CC-01 Porch Report (daily) · RK-01 JP Poll (weekly in-season) · GD-01 Game Breakdown · GD-08 Game Grade · GD-14 Watch List · GD-21 Saturday Blueprint · GD-16 What We Learned · GD-22 Sunday Truths · PR-01 Weekly Picks · MD-03 Josh vs. the Model · PO-01 Playoff Picture (Oct–Jan) · NR-01 What It Means (event-triggered, franchise-grade) · PR-06 Receipts (midseason + January) · PS-10 Field Manual (annual) · TP-03 Portal Tracker (windows).

## 3. GAME WEEK TIERS (the volume governor)

**TIER A — THE PATE STATE GAME OF THE WEEK (one game).** The full treatment, 7–10 pieces on the fixed rhythm, all attached to the game hub: Mon GD-13 stakes → Tue GD-05 *or* GD-06 (whichever matchup layer is the actual story) + GD-07 → Wed GD-08 Game Grade → Thu GD-01 flagship → Fri GD-03 keys (both editions) + GD-11/GD-12 predictions → Sat AM inside GD-14 → Sat night GD-15 → Sun folded into GD-16.

**TIER B — MARQUEE GAMES (2–4).** Each: GD-02 preview · GD-03 keys (one combined edition) · GD-11+GD-12 combined prediction piece · postgame inclusion in GD-15/16. ~3–4 pieces.

**TIER C — REST OF SLATE.** Covered entirely by GD-20 Slate Guide · GD-14 Watch List · PR-01 Picks · GD-17 Upset Alert. No standalone previews.

**Anti-cannibalization rule:** within one matchup, no two articles answer the same question. The engine checks the hub's existing modules before commissioning. Duplication is a commissioning failure.

## 4. THE GAME HUB

For every Tier A game (and all CFP games), one canonical matchup URL is created Monday and accumulates all week: `/college-football/georgia-vs-alabama-2026/`. Mon: GD-13 leads → Tue–Wed: matchup layers + Game Grade attach → Thu: GD-01 becomes the centerpiece → Fri: predictions + live Ledger entries → Sat: watch items + verified availability → Sun: final, GD-16 grading of our own claims, Ledger resolution. One SEO object accumulating authority instead of six pages competing. Standalone pieces cross-link into it; the homepage dedup treats hub modules as already-shown content IDs.

## COMMISSIONING RULES (for the selection engine and Claude Code)

1. **No article without an ID.** If a needed piece has no ID, propose one (bucket, class, tier, trigger), get approval, then write.
2. **T1 cadence is non-negotiable; T3/T4 require a fired trigger,** never an idle slot to fill.
3. **Route to the spec:** GD/RK/PR/MD/PS/PE/FA/CC Josh-voice pieces → `06-spec-features.md`. Wire + autonomous NR/TI-05/SD → `04-spec-wire.md`. PS-01/02/03 → `05-spec-annual.md`.
4. **Check before commissioning:** the consistency ledger (predictions), the game hub (duplication), `07-current-state.md` (stamp).
5. **Measure per ID:** pageviews, engaged time, registration conversion, Pick'Em conversion, production cost — so allocation is tunable quarterly.
