# V2 Phase 2 — The Porch Community MVP

Source: `docs/pate-state-v2-brief.md` §3 (product spec), §12 Phase 2 (scope +
acceptance). Brand: The Porch. Nav label: Community. Routes: /community,
/community/[boardSlug], /community/thread/[threadId].

Acceptance targets: citizens create/participate in discussions; staff can
pin/lock/hide/moderate; report + mute work; auto game threads for major
games; excellent mobile; new threads noindex; board list matches the §3.1
bold/scannable standard.

- [ ] T1 Migration 0008: citizens.role (citizen|staff); boards (seeded:
      front-porch, recruiting-portal, game-day, film-room, fantasy-games,
      ask-josh + 10 team porches); threads (types, pinned/locked/hidden,
      reply_count/view_count/last_reply, staff-only types enforced, nullable
      author for system game threads); posts (quote, edit window); reactions
      (thread+post upvotes); reports; mutes; moderation_log (immutable);
      is_staff() helper; column-guard trigger (only staff flip pinned/locked/
      hidden); reply-count trigger; cron: daily game-thread creation via
      call_site_endpoint allow-list. First citizen (Isaac) → staff.
- [ ] T2 lib/community.ts (public reads via cookie-less anon client so
      homepage stays static: boards+latest threads, board threads, thread+
      posts+reaction counts, trending) + lib/moderate.ts (Haiku triage
      low/medium/high, 4s timeout, FAIL-OPEN; high → hidden + auto-report).
- [ ] T3 Server actions: createThread (type rules: rumor never "confirmed",
      news prompts source link), createPost, toggleUpvote, report, mute,
      staff pin/lock/hide (RLS enforces staff) + moderation_log entries.
- [ ] T4 Pages: /community (board directory + "Latest on the Porch" per
      §3.1 spec), /community/[board] (thread list + new-thread composer,
      GateCard when signed out), /community/thread/[id] (posts, reply
      composer, upvotes, report, quoted replies, staff controls inline).
      §3.1 CSS: navy header bar w/ kicker + big white title, white cards on
      gray bg, 19–21px extra-bold titles, avatar initials disc (+ favorite-
      team chip), reply/view counts right-aligned, hot-thread accent border,
      footer VIEW ALL THREADS bar, RelTime timestamps, ≥44px touch targets.
      Thread pages robots noindex (all threads start noindex per §8).
- [ ] T5 /community/mod: staff-only report queue (resolve/dismiss, jump to
      target) + moderation log view.
- [ ] T6 /api/community/game-threads (cron-guarded): creates Game Day
      threads for today's marquee real games (CFBD); scheduled daily in
      season; no-ops until games exist.
- [ ] T7 Wiring: nav Community → /community; porch page cross-links; article
      pages get "Discuss this on the Porch" (§3.8); homepage "Trending on
      The Porch" module (renders ONLY with real threads — §0.1).
- [ ] T8 Build, deploy, browser-verify (create a real test thread), memory.

Deferred within Phase 2 (noted for the wrap-up): polls-in-threads,
notifications bell, badges/reputation engine, board-level search, thread
indexing thresholds (all threads stay noindex until the quality gate
exists), Porch Take of the Week.
