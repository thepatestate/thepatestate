# V2 Phase 4 — Competition Engine + Launch Games (brief §5.1, §5.2, §12 Phase 4)

Goal: ONE reusable competition engine (never hard-code games separately), powering the
two competitions that must be real before the Aug 29 opener:

1. **Pate State Playoff Challenge — Window 1 (Preseason)**: pick the 12-team field,
   seed it, crown a champion, championship-total-points tiebreaker. Scoring already
   promised on /playoffs: +10 per team in the real field, +25 exact seed, +100 champion.
   Locks at first Week 1 kickoff.
2. **Week 1 Pick'Em**: 10 marquee games, pick winners + confidence points 1–10 (each
   used once). Copy on /pickem promises "picks lock Saturday 11:58 AM ET" — lock
   2026-08-29T15:58:00Z (2 min before the noon-ET kickoff).

Brief acceptance (Phase 4): private groups end-to-end · picks lock immutably
(timestamped, audit-logged, scoring-rule version recorded) · results from the official
data source · group and national scoring identical · AI recaps read real data only.

Deferred to later sub-phases (explicitly NOT now): Playoff Team Draft + draft rooms +
AI personas (§5.3), fantasy (§5.4), AI Draft Simulator (§5.5), Beat Pate/Survivor/etc.
(§5.6), AI round recaps + share-card images (no games played yet — hook when Week 1
results exist), badges/notifications, custom scoring templates (commissioner picks
from templates later; both launch comps use the standard template).

Hard rules: no paid entry, no wagering (§5.7). Entries require citizenship (free).
Terms: entry records terms_version. LLM never calculates scores (§5.1) — scoring is
pure deterministic code reading official finals (ESPN feed; CFBD cross-check).

## Decisions

- Both comps lock at a single competition-level locks_at (simplest immutability that
  matches published copy); per-game rolling locks are a later enhancement.
- Josh's official bracket entry (is_official, author_label "Josh Pate") seeds ONLY
  from his real published bracket column (verify picks match the article) — never
  invented; if ambiguous, ship without it and link the column instead.
- ESPN game ids are the canonical result keys (quota-free live finals); CFBD used as
  cross-check when both report.
- Groups reuse ONE community system for discussion later (link, not a parallel
  message system) per §12 "build ONE of each".
