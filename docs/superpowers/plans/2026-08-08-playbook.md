# The Playbook (Sub-project D) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A daily 6 AM ET email to opted-in confirmed citizens — latest episode + latest published articles + honest CTA — sent via Resend, subject/intro by Claude, one-click unsubscribe, idempotent per day.

**Architecture:** pg_cron → `POST /api/playbook/send` → guard (cron secret) → idempotency claim in `playbook_sends` → recipients from Supabase (service role) → content from Sanity → Claude subject/intro (fallback constants) → Resend batch → footer unsubscribe links HMAC-signed, handled by `GET /api/playbook/unsubscribe`.

**Tech Stack:** existing deps only (`@supabase/supabase-js` admin client, `@anthropic-ai/sdk`, fetch → Resend REST). No new packages.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-08-playbook-design.md`.
- Truthfulness: only real content; zero published articles → that section omitted; never send when Sanity is unreachable; no ritual claims for unbuilt engines.
- Anthropic rules (as sub-project C): model `claude-sonnet-5`, no sampling params, structured outputs json_schema (`additionalProperties: false` + `required`), `max_tokens 256`, `output_config.effort "low"`; fallback constants on any failure (`subject: "The Playbook — The Pate State"`, intro: `"Here's what's new on the porch."`).
- `SUPABASE_SERVICE_ROLE_KEY` is server-only: used ONLY inside API routes, never imported by pages/components, never NEXT_PUBLIC.
- Unsubscribe sig: HMAC-SHA256(hex) of the auth user id keyed with `CRON_SECRET`; compare with timingSafeEqual (length-checked).
- All sends from `The Pate State <porch@thepatestate.com>`; `List-Unsubscribe` header set; porch voice, no exclamation points.
- Console logging convention `[playbook]` in every catch; fail-soft per spec's skip conditions.
- Branch `build/playbook` off main. Identity `thepatestate`. `npm run build && npm test` green per task.

```sql
alter table public.citizens add column if not exists playbook_opt_out boolean not null default false;

create table if not exists public.playbook_sends (
  send_date date primary key,
  recipients int not null default 0,
  sent_at timestamptz not null default now()
);
alter table public.playbook_sends enable row level security;
-- no policies: service-role only

create or replace function call_site_endpoint(path text) returns void
language plpgsql security definer
set search_path = pg_catalog, public
as $$
declare
  secret text;
begin
  if path not in ('/api/ingest/poll', '/api/ingest/enrich', '/api/youtube/subscribe', '/api/playbook/send') then
    return;
  end if;
  select cron_secret into secret from private_cron_config where id = 1;
  if secret is null then return; end if;
  perform net.http_post(
    url := 'https://thepatestate.com' || path,
    headers := jsonb_build_object('x-cron-secret', secret, 'Content-Type', 'application/json'),
    body := '{}'::jsonb,
    timeout_milliseconds := 120000
  );
end;
$$;
revoke execute on function call_site_endpoint(text) from public, anon, authenticated;

select cron.schedule('send-playbook', '0 10 * * *', $$select call_site_endpoint('/api/playbook/send')$$);
```

### Task 2: Playbook lib (TDD) — sig helper + HTML assembly

**Files:** Create `lib/playbook.ts`, `lib/playbook.test.ts`

**Interfaces:**
- Produces: `signUid(uid: string): string`; `verifyUid(uid: string, sig: string): boolean`; `interface PlaybookContent { episode: { ytId: string; title: string; thumbnailUrl?: string } | null; articles: Array<{ headline: string; dek?: string; slug: string }> }`; `renderPlaybookHtml(c: PlaybookContent, opts: { intro: string; unsubscribeUrl: string }): string`; `renderPlaybookText(...same): string`.

- [ ] **Step 1: Failing tests** covering: sign/verify roundtrip; verify rejects tampered sig and wrong length; html contains episode watch link, article links (`/notebook/<slug>`), the intro, and the unsubscribe URL exactly once; zero-article variant omits the articles heading; text variant contains the same links.

```ts
import { describe, it, expect } from "vitest";
import { signUid, verifyUid, renderPlaybookHtml, renderPlaybookText } from "./playbook";

const content = {
  episode: { ytId: "abcdefghijk", title: "Weekend Truths", thumbnailUrl: "https://i.ytimg.com/vi/abcdefghijk/hqdefault.jpg" },
  articles: [{ headline: "The Case For Texas", dek: "A look.", slug: "the-case-for-texas" }],
};
const opts = { intro: "Here's the porch this morning.", unsubscribeUrl: "https://thepatestate.com/api/playbook/unsubscribe?uid=u1&sig=s1" };

describe("uid signing", () => {
  it("roundtrips", () => { const s = signUid("user-123"); expect(verifyUid("user-123", s)).toBe(true); });
  it("rejects tampering", () => { expect(verifyUid("user-124", signUid("user-123"))).toBe(false); });
  it("rejects garbage lengths", () => { expect(verifyUid("user-123", "ff")).toBe(false); });
});

describe("renderPlaybookHtml", () => {
  it("includes episode link, article link, intro, unsubscribe once", () => {
    const html = renderPlaybookHtml(content, opts);
    expect(html).toContain("youtube.com/watch?v=abcdefghijk");
    expect(html).toContain("/notebook/the-case-for-texas");
    expect(html).toContain(opts.intro);
    expect(html.split(opts.unsubscribeUrl).length - 1).toBe(1);
  });
  it("omits articles section when empty", () => {
    const html = renderPlaybookHtml({ ...content, articles: [] }, opts);
    expect(html).not.toContain("From the Notebook");
  });
});

describe("renderPlaybookText", () => {
  it("carries the same links", () => {
    const t = renderPlaybookText(content, opts);
    expect(t).toContain("youtube.com/watch?v=abcdefghijk");
    expect(t).toContain("/notebook/the-case-for-texas");
  });
});
```
