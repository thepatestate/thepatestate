# Homepage v5 "Final Direction" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the site's global chrome (masthead, rhythm bar, footer) and rebuild the homepage as the light ESPN/SI-style "v5 Final Direction" front page, wired to live data, then deploy to production.

**Architecture:** The v5 mockup's CSS is ported into `app/v5.css`, scoped under a `.v5` class so it cannot leak into interior pages (which keep the dark chalk theme under the new chrome). The homepage becomes a thin server component composing ~14 section components in `components/home/`, each fed by existing lib fetchers with `.catch`-guarded honest fallbacks. Chrome components live in `components/chrome/`.

**Tech Stack:** Next 16.3 App Router (server components), next/font/google, Sanity, Supabase, CFBD/ESPN feeds, YouTube Data API, vitest.

**Spec:** `docs/superpowers/specs/2026-08-16-homepage-v5-design.md`
**Mockup (canonical markup + CSS):** checked into `wireframes/homepage-v5.html` by Task 1 (source: `~/Desktop/pate-state-homepage-v5.html`).

## Global Constraints

- **§0.1 honesty rule:** fictional content (fake counts, fake games, fake threads, fake products' claims) may render ONLY when `DEMO_MODE` (`lib/demo.ts`) is true. Production shows real data, count-free copy, `EmptyState`, or nothing.
- **CSS isolation:** every rule in `app/v5.css` must be scoped under `.v5` (descendant `.v5 .foo` or compound `.v5.foo` / `.v5-header` / `.v5-footer`). NO bare element or class selectors at top level. Existing `globals.css` is NOT edited except where a task explicitly says so.
- **Images:** use `next/image`. Remote images (ESPN logo CDN `a.espncdn.com`, YouTube `i.ytimg.com`) follow the existing pattern — these hosts are already configured; do not add new remote hosts.
- **Routes preserved:** `/notebook /show /scores /poll /recruiting /play /community /me /search /join /wire /shop /tailgate /report /playoffs /porch /about /standards /privacy /terms /contact`. Thread links: `/community/thread/[id]`.
- **Fonts:** Barlow Condensed (weights 500–800) + Public Sans (variable) via `next/font/google`, exposed as `--v5-cond-f` / `--v5-sans-f`. Existing display/body/mono fonts stay loaded (interior pages use them).
- **Data field names (do not guess):** `Video {id, title, published, thumbnail}` (`published`, NOT publishedAt); `SlateGame {away, awayCode, awayLogo, home, homeCode, homeLogo, when, net}`; `ThreadSummary {id, board_slug, title, thread_type, pinned, locked, hidden, reply_count, view_count, last_reply_at, created_at, author_label, citizens?: {display_handle, favorite_team, role}}`; Sanity article `{_id, slug.current, headline, dek?, byline, publishedAt?, heroUrl?, episode?.series?}`; wire item `{_id, headline, category?, teams?, publishedAt, storySlug?, sourceUrl?, sub?}`.
- Type-check per task with `npx tsc --noEmit`; full `npm run build` at Tasks 3 and 13.
- Commit after every task with a `feat(home-v5): …` / `feat(chrome-v5): …` message ending in the Claude co-author trailer.
- This Next version has breaking changes (AGENTS.md). Mirror patterns already in this repo (they are known-good on Next 16.3); if you need an API not used in the repo, read the matching guide under `node_modules/next/dist/docs/01-app/` first.

## CSS Porting Recipe (used by Tasks 1–12)

The mockup's `<style>` block (`wireframes/homepage-v5.html` lines ~9–410) is the single source of CSS truth. Each task copies its section's block into `app/v5.css` applying these transforms **exactly**:

1. `:root{…}` → `.v5{…}` (Task 1 only), with the three font vars redefined:
   `--cond:var(--v5-cond-f),sans-serif; --slab:var(--v5-sans-f),sans-serif; --body:var(--v5-sans-f),sans-serif;`
   All other custom properties copied verbatim (they are scoped to `.v5`, so `--gold`/`--navy`/`--ink`/`--red` cannot collide with globals).
2. `*{margin:0;padding:0;box-sizing:border-box}` → `.v5, .v5 *{margin:0;padding:0;box-sizing:border-box}`
3. `body{…}` → merge `font-family:var(--body);color:var(--ink);-webkit-font-smoothing:antialiased` into the `.v5{…}` block. Page background comes from `.v5-page{background:var(--white)}` (homepage `<main>` only).
4. `html{scroll-behavior:smooth}` → drop (already global).
5. `a{…}` → `.v5 a{…}`; `img{…}` → `.v5 img{…}`.
6. `header{…}` → `.v5-header{…}` · `footer{…}` → `.v5-footer{…}` · selectors starting `.rhythm` → compound on the root: `.rhythm{…}` → `.v5.rhythm{…}`, but `.rhythm .wrap` → `.v5.rhythm .wrap`.
7. Every other selector gets the `.v5 ` descendant prefix: `.feat h1` → `.v5 .feat h1`. Comma lists: prefix each member.
8. `@keyframes pulse` → rename `v5pulse` and update the two `animation:` references.
9. `@media(max-width:1080px)` / `@media(max-width:760px)`: keep the queries, prefix the selectors inside per rules 6–7.
10. `nav.main` selectors live inside the header: `.v5-header nav.main{…}`.

`next/image` with `fill` requires the parent to be positioned: the mockup's `.thumb`, `.th`, `.short`, `.prod img` containers that aren't already `position:relative` get `position:relative` added — note each addition with a `/* fill anchor */` comment.

- [ ] **Step 3: Write `components/chrome/Masthead.tsx`**

Client component modeled on `Nav.tsx` (keep its More-menu outside-click effect and drawer behavior verbatim), v5 markup:

```tsx
"use client";
import { useEffect, useRef, useState } from "react";
import Link from "next/link";
import { usePathname } from "next/navigation";
import NavSession from "@/components/NavSession";

const LINKS = [
  { href: "/notebook", label: "Latest" },
  { href: "/show", label: "Show" },
  { href: "/scores", label: "Scores" },
  { href: "/poll", label: "Rankings" },
  { href: "/recruiting", label: "Recruiting" },
  { href: "/play", label: "Play" },
  { href: "/community", label: "Community" },
] as const;

const MORE_LINKS = [
  { href: "/teams", label: "Teams" },
  { href: "/tailgate", label: "Tailgate" },
  { href: "/porch", label: "The Porch Tour" },
  { href: "/report", label: "The Report" },
  { href: "/shop", label: "Shop" },
  { href: "/about", label: "About" },
  { href: "/standards", label: "Standards" },
  { href: "/contact", label: "Contact" },
] as const;

export default function Masthead() {
  const [open, setOpen] = useState(false);
  const [moreOpen, setMoreOpen] = useState(false);
  const moreRef = useRef<HTMLDivElement>(null);
  const pathname = usePathname();

  useEffect(() => {
    if (!moreOpen) return;
    const close = (e: MouseEvent) => {
      if (moreRef.current && !moreRef.current.contains(e.target as Node)) setMoreOpen(false);
    };
    document.addEventListener("mousedown", close);
    return () => document.removeEventListener("mousedown", close);
  }, [moreOpen]);

  return (
    <header className="v5 v5-header">
      <div className="wrap mast">
        <Link className="logo" href="/">
          <span className="name">The Pate <em>State</em></span>
          <span className="kicker">The Front Porch of College Football</span>
        </Link>
        <nav className="main">
          {LINKS.map((l) => (
            <Link key={l.label} href={l.href} className={pathname === l.href ? "active" : undefined}>
              {l.label}
            </Link>
          ))}
          <div className="nav-more" ref={moreRef} style={{ position: "relative" }}>
            <button type="button" aria-expanded={moreOpen} aria-haspopup="menu" onClick={() => setMoreOpen(!moreOpen)}>
              More ▾
            </button>
            {moreOpen && (
              <div className="more-menu" role="menu">
                {MORE_LINKS.map((l) => (
                  <Link key={l.label} href={l.href} role="menuitem" onClick={() => setMoreOpen(false)}>
                    {l.label}
                  </Link>
                ))}
              </div>
            )}
          </div>
        </nav>
        <div className="right">
          <Link className="myteams" href="/me">♡ My Teams</Link>
          <Link className="search" href="/search" aria-label="Search">⌕</Link>
          <NavSession fallback={<Link className="join" href="/join">Join Free</Link>} />
          <button className="menu-btn" aria-expanded={open} onClick={() => setOpen(!open)}>Menu</button>
        </div>
      </div>
      <div className={open ? "drawer open" : "drawer"}>
        {[...LINKS, ...MORE_LINKS].map((l) => (
          <Link key={l.label} href={l.href} className={pathname === l.href ? "active" : undefined} onClick={() => setOpen(false)}>
            {l.label}
          </Link>
        ))}
        <Link href="/join" onClick={() => setOpen(false)}>Join Free</Link>
      </div>
    </header>
  );
}
```
