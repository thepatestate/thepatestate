## What's running

- **Stack**: Next.js on Vercel (auto-deploy from `main`, ~90s) · Sanity (articles, episodes, wire) · Supabase (citizens, games, cron, wire clusters) · secrets in `.env.local` + the Vercel dashboard.
- **Writers**: prose by **OpenAI gpt-5.6-luna** (`lib/writer.ts` — default whenever `OPENAI_API_KEY` is set; `WRITER_PROVIDER=anthropic` opts out). Verification — fact-check gate, quote extraction, series classification — stays on **Claude Sonnet**, deliberately a different vendor than the writer.
- **Editorial law**: Josh's **Voice Manual v2.2** (`prompts/voice-manual.md`) and **Article Playbook v3.0** (`prompts/article-playbook.md`); distilled per-call rules in `prompts/global-preamble.md`. Gold-standard example: `docs/content/annual-ohio-state-v6-master.html` (+ text extraction `ohio-state-2026-preseason-annual.md`).
- **Cadence**: wire monitor every 10 min, 10–23 & 0–4 UTC (≈6 AM–1 AM ET, `supabase/migrations/0006`) · YouTube poll every 15 min · Playbook newsletter daily 6 AM.

## The content machine

**Show → Notebook articles**: episode ingest → transcript (YouTube captions API on a durable production OAuth grant; Supadata backup) → verbatim quote extraction into `josh_quotes` (Supabase) → first-person companion article as Josh with hard rails (every claim traces to transcript; quoted spans verified verbatim; low-confidence drafts hold in Studio, never auto-publish). Entire 46-article archive re-voiced 2026-08-19 under v2.2.

**News → The Wire**: sources are ESPN (site API — their RSS is abandoned), CBS Sports, Yahoo Sports, On3 (grounded via feed `content:encoded`; their pages block fetchers — text persists on `wire_clusters.source_text`). Cluster → item → full-story attempt through the §21 stack (banned patterns → no-attribution gate → second-model fact-check). Failures stay storyless **by design**; the monitor self-heals the backlog each run (3 attempts/item cap via `wire_clusters.backfill_attempts`). **X integration: decided against** (free path ≈15–40 min behind a tweet via the outlets).

**House rules the code enforces**:
- Clicks never leave the site: no outbound links on wire list surfaces; the homepage Latest rail renders only items with an on-site story; credit is plain text in lists, an italic footer on stories.
- No in-prose attribution ("Per ESPN's report…" is *rejected* by `hasAttributionOpener` — flipped 2026-08-20; 151-story archive cleaned).
- No outlet names in headlines (`cleanHeadline` + `headlineNamesOutlet`; "Rivals" matched case-sensitively; 248 archive headlines rewritten).
- The bold quote is the story quoting itself (`callout`, substring-verified via `validCallout`); **Josh's Receipt** renders only after a relevance check (audit dropped 201 of 206 loose matches).
- Never fabricate Josh: unaddressed news is never voiced as his opinion; his voice enters wire stories only via archived verbatim quotes.
