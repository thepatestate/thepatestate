# Review format

Write the review in this order. Quote sentences exactly. Never say "consider"; say what to do.

```
VERDICT: <one line — would a national college football desk run this as written? yes / with edits / no — and the single biggest reason>
FORM: <item | brief | story | reported feature | column> · <words> words · <n> quotes · <n> time anchors

THE THREE THINGS
1. <the biggest problem, named as a tell number from ai-tells.md> — "<the exact sentence>" → <what to write instead, as a sentence>
2. …
3. …

THE MISSING MOVES (from craft-notes.md; pick the two that would change the piece most)
- §<n> <move> — <where in this piece it belongs and what it would say, using only facts the piece already has>

REWRITE THE LEAD
<the new first sentence or two, using only facts in the piece>

REWRITE THE KICKER
<the new last sentence, using only facts in the piece>

SENTENCE LIST (everything else, one line each: "<sentence>" → <fix>)

UPSTREAM (only if the fix is not in the prose: wrong subject for the desk, no quotes in the source, no date in the source)
```

Rules for the reviewer:
- Add no facts. Every rewrite uses only what the piece or its sources already carry.
- Do not add a mandatory beat (concession, "what I'm watching," porch close). The corpus does not have them.
- A columnist's section headers, a dare, a dated concession or a triad are a person's habits, not tells.
- Third-person desk copy stays third person; Josh's Read stays first person, signed — JP.
